## Portfolio-Website
Portfolio website build using HTML5, CSS3, JavaScript and jQuery.

## Run locally

Node.js is required. From the project folder, run:

```sh
npm start
```

Then open http://localhost:8000 in your browser. To use a different port, set
the `PORT` environment variable before starting the server.
